# Overview

Renzo Gracie Jiu Jitsu (Kaysville, Utah) asked Scott to help with IT / information systems. The immediate need is **customer acquisition**.

The gym already runs Facebook advertising with Instagram connected. The exact Meta setup is still being inventoried ([[Open-Questions]]). Meta is an external acquisition source, not the core domain ([[Funnel]]).

Scott’s role is to build and operate an acquisition **system**. Social platforms are input channels, not the product.

V1 is operated by Scott. Roles `ADMIN` / `STAFF` / `VIEWER` are enforced: ADMIN runs the gym’s acquisition console including user admin; STAFF does CRM; VIEWER sees the dashboard only. Do not hard-code workflow to one person.

**Out of scope for V1** (from the original spec, still in force): billing, POS, class attendance as a gym scheduler, belt tracking, payroll, inventory, waivers, tournaments, a full website CMS, accounting.

The old marketing website in this repo is **not** part of this application. Public acquisition surface is `/trial` ([[Intro-Scheduling]]).
