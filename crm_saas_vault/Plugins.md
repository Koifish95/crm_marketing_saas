# Plugins

The vault must remain readable as Markdown without plugins.

## Required community plugin: Dataview

**Why:** [[ToDo]] should list outstanding checkboxes from other notes instead of duplicating task text.

**Install:** Obsidian → Settings → Community plugins → Browse → Dataview → Enable.

Core plugins already used: file explorer, search, backlinks, outgoing links, tags, outline, page preview.

No other community plugins are required. Do not make a fact exist only inside a Dataview query; the source checkbox must still be in a normal note.
