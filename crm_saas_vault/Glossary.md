# Glossary

| Term | Meaning |
|---|---|
| Lead | Person we contact. Guardian for kids programs. |
| Program | Configurable offering row (`ADULT_BJJ`, `KIDS_BJJ`, `STRIKING`, `WRESTLING`). Not a code enum. |
| Participant | Person who attends. Same as Lead for adults. |
| Trial | One scheduled intro attempt. Many per Lead. |
| Intro availability | Recurring weekly rule plus date exceptions that produce public `/trial` slots. Not a class scheduler. |
| FollowUpTask | Acquisition phone-call work after an intro is scheduled or an event is processed. |
| Marketing Task | Collaborative marketing work item. Not Lead Follow-up. |
| Campaign | Internal acquisition/marketing effort, not a Meta campaign. |
| ContentItem | Planned social/content record with optional approval and manual publication history. |
| Acquisition Event | Gym event with sessions and registrations; Leads are created only by batch process. |
| Access Right | Code-catalog marketing permission granted through User Roles. ADMIN always has all of them. |
| Compensation Attribution | Per-person credit for earned compensation, separate from acquisition source and Follow-up ownership. |
| JOINED | Staff/Scott marked the person a member. Not a payment event. |
| V1 | Usable acquisition + marketing-operations app through current [[Milestones]] M0–M9 (revised sequence). |
